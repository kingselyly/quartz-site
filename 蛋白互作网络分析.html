蛋白互作网络（PPI）

系统生物学的核心方法。

传统方式：
手动上传 → 等待分析 → 下载结果 → Cytoscape画图 → 至少半天

STRING + NetworkX：
15分钟完成全流程！

STRING数据库：

  • 5000+生物
  • 2400万蛋白质
  • 2000万互作关系

构建PPI前明确这4件事

输入列表来源

先说明基因来自差异表达、GWAS、蛋白组还是文献整理，并保留原始筛选阈值。

物种与ID体系

人、小鼠、大鼠网络不能混着跑；Gene Symbol、Ensembl、Entrez要统一后再送入STRING。

置信度阈值

建议：

  • ≥0.7：高质量
  • ≥0.9：最高质量

阈值越高，互作越可靠，但网络规模越小。

分析目标

找hub gene？找模块？做图？还是缩小候选范围？目标不同，解读重点也不同。

一次可复核的PPI分析交付这4样

互作边表

至少导出节点、边、置信分数和证据来源。

拓扑指标结果

把degree、betweenness、closeness整理成表，hub gene才有量化依据。

重点子网络图

通常需要：1张主网络图 + 1张重点模块图

候选优先级说明

结合差异表达、文献和临床关联证据说明入选理由。

实战：PPI网络分析

Step 1: STRING查询

genes = ["TP53", "MYC", "EGFR", "KRAS", "PTEN",
         "PIK3CA", "AKT1", "MTOR", "MAPK1", "STAT3"]

# STRING查询设置：
# - 物种：人类
# - 置信度：>0.7

Step 2: NetworkX拓扑分析

import networkx as nx

G = nx.Graph()
G.add_edges_from(interactions)

# 度（Degree）
degrees = dict(G.degree())

# 介数中心性
betweenness = nx.betweenness_centrality(G)

# Hub基因（度>5）
hub_genes = [g for g, d in degrees.items() if d > 5]

拓扑指标含义：

  • 度：节点的连接数，高=参与更多互作
  • 介数中心性：信息传递的关键节点
  • 聚类系数：邻居节点之间的连接密度

Step 3: 功能模块检测

from community import best_partition

partition = best_partition(G)

# 模块0: 细胞周期
# 模块1: 信号转导
# 模块2: 代谢调控

Step 4: 可视化

可视化技巧：

  • 节点大小：与度成正比
  • 节点颜色：表示模块归属
  • 边粗细：与置信度成正比

4个误读点

Hub gene ≠ 致病驱动基因

连接度高≠一定是疾病核心驱动因素

STRING互作 ≠ 样本里已证实

STRING整合了多来源证据，不自动代表在你组织、疾病状态下真实存在。

阈值太松，网络越大越”假热闹”

低置信边全部保留=更难解释，更容易挑出假热点

脱离表达与文献单独讲网络

单看拓扑结构很容易过度解读，最好把PPI与差异表达、功能富集一起讲。

注意事项

基因名映射：
分析前确保基因名格式一致，建议使用Gene Symbol。

网络规模：
基因>500会导致网络过于复杂，建议先筛选差异基因。

Hub基因≠致病基因：
只是网络中连接度高的基因，需要结合表达差异、临床关联、功能验证等证据。
